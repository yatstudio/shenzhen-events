视频：https://www.youtube.com/watch?v=rwueq7n_3yA ｜时长 37 分钟｜郭宇主题演讲「软件的终结」+ 现场演示 + 对谈（主持人为一位非虚构作家） 说明：机器转写，繁简混杂、专名多有误听（Claude 转写为「Cloud/Cloudy」，OpenClaw 转写为「OpenCloud」，Cowork 转写为「Codework」，Typeless 转写为「Typlus」，均按上下文校正）；文中行业与市场说法为讲述者现场观点，未经核实。

一句话

这场的主题词是「软件的终结」。郭宇的断代判断：真正的分水岭不是 2022 年 12 月的 ChatGPT，而是去年 10 月 Claude Code 推出 Skill（技能）——从那一刻起，软件从「写死的固定代码」变成「随需流动的 token」，任何工作只要能被写成一份文档，就能被自动推理执行。结论推到底，就是标题那句：短期它让你一个人抵一万人，长期它让知识工作本身不再需要人——「享受最后六个月有意义的工作」是他引述的一位名人（Dario Amodei 式）的说法，他基本认同，唯一的缓冲是推理成本。

论证链

  1. Skill 是什么：把你的工作写成文档——早上起来干什么、查完邮件干什么、开完会决定什么——Markdown 格式即可。这份文档就是技能；Claude Code 读了它，会现写代码、自动执行。传统软件流程（想需求→和产品经理对齐→冻结需求→写技术文档→写代码→发布）被整体跳过。
  2. 于是文理分科消失：他自己就是活证据——本科政治学、文科出身，2008 年高考后自学代码，2011 年进支付宝做年度账单，2014 年与沈正宇在中关村创业、10 个月后被字节收购（当时字节只有 200 多个工程师，世人只知今日头条），2015 年 3 月在冲绳居酒屋，张楠和张一鸣聊到 4G 资费降到百元以下「可以试试视频推荐」，才有了火山小视频和 2016 年 12 月发布的抖音。他在字节六年半，2020 年辞职旅日至今。
  3. 为什么 2023–2025 年不算数：ChatGPT 出来两年，讨论却陷入「是不是泡沫」，因为用户量 plateau 了。他本人那两年以投资人身份旁观，agent 对他写代码「没有什么帮助」，直到去年 11 月才回归写代码。变化发生在去年 10 月之后：原来任何工作都能通过自动推理完成——能写代码，就能分析财务、分析法律、做任何事。市场信号是：此后 Claude 每发布一个新东西，就有一家上市公司暴跌 20%（图片处理不再需要 Adobe、文档不再需要一众 SaaS，因为它能用你的文件、你的登录状态、你的云盘，现写一个完全为你定制的工具）。
  4. Vibe Coding 的本质：Opus 4.5 之后跨过门槛——你不再需要监督它写的代码，它就能正常工作。「它在写代码，我在旁边跳舞、在旁边嗨，我只要思考我到底要做什么。」程序员的工作只剩下想清楚要什么，然后沟通。
  5. OpenClaw（龙虾）的位置：它不是模型，是编排软件——有心跳、常驻你的 Mac mini，通过微信/Telegram 接收指令，24×7×365 用「记录需求→现写代码」的方式替你办事。但他提醒风险：已经看到很多 OpenClaw 在本地被别的 agent 骗钱的例子；跑在云端沙箱（用完即焚）则没有这个风险——这正是云端化 agent 产品的机会。中美模型差距约 6–12 个月，主要在编码能力（Opus 4.6），而现在 6 个月就是生死线。

现场演示（信息量最大的一段）

主持人想给自己的写作做个新网站（他原先用 WordPress）。郭宇用 Claude Cowork + Typeless 语音输入，全程说话：

  • 先让 Claude 读他的硬盘/个人资料，它自己 web search 补齐了他的履历（非虚构作家、代表作、在上海、首尔、东京三地居住过——标语自动写成 "From Shanghai to Seoul to Tokyo"）。
  • 让它加载设计技能：电脑上没装，他说了一句「用 UI/UX Pro Max 这个技能去做」，Claude 自己搜索、自己安装了 7 个设计相关 Skill，再按专业设计师的方法重构网站：先读完旧站全部内容与布局，设计一套设计系统，然后写代码。
  • 两三分钟出站，还可一键做中日英三语版。他的点评：「一切都不再需要依赖搜索引擎——或者说，依赖搜索引擎的已经不再是人，而是它。」WordPress 这类平台理论上不再必要（当然你想用 WordPress 重构，它也能用 WordPress 给你重构）。

行业冲击顺序与机制

  • SaaS 先死：企业向的 Salesforce、各类 HR 系统首当其冲，因为企业用户会发现自己现写更合身。
  • 程序员最先失业，且已经开始：硅谷很多公司已完全不招初级程序员——招人进来不如直接让 Claude Code 写，效果更好，而且省掉了和人沟通这个最大的摩擦；agent 可以 24 小时跑、失败成本极低，不用雇人也不用裁人。
  • 写作与出版：知识可以随用随取，Claude 可以是任何作家、任何哲学史博士。他本人写书就用 Claude Code 做研究——Google 搜索一屏只给几个结果，它能把全网搜完直接写成稿。
  • 法律：现场他让 AI 现查——Claude 2 月推出的 legal 插件，据彭博报道引发了约 2,850 亿美元的法律服务公司股票抛售。他确认影响的不是助理层，而是整个企业法务团队。他的政治学解释更深一层：法律是为解决人和人、人和群体、群体和群体之间的摩擦而存在的；agents 如果共享记忆、让所有事自动「on the same page」，摩擦大幅消失，法律仍会存在，但会失去执行的意义。
  • 宏观的拧巴：生产力在暴涨，但生产关系的分配原则没变——用 AI 的公司利润涨、同时裁员，岗位减少→消费者减少→通缩压力，市场正在给这个「非常不稳定的未来」定价。另一面：就算失业了，一个人每月订 200 美元的 Claude，也许还能做出点能赚钱的事。「没人知道。」

给年轻人的建议（很反直觉）

  • 别再学写代码了：还没开始的就不用学了。学怎么用 agent，三到六个月足够；而在这之后连这个都不用学，因为全自动化了。
  • 他自己正在写一个 OneMan AI：昨晚睡前让它在家里的 5090 PC 上跑，一夜 1,000 个循环、6 个多小时，任务是「设计一家东京的装置艺术公司」——完整的财务计划、网站、3D 装置作品，并写邮件把作品投给东京所有画廊和公共空间，全部做完。
  • 由此他把软件分成两类：写死的软件（过去工程师构建的那种）和最终的软件——通过不断推理把人的思考变成无数可能性并行展开，你挑效率最高的那条分支，或者干脆不挑、让它全自动运行。创业的意义随之改变：在日本开公司原本要 800 万日元注册资本、要招人、想法太多还会分散精力导致失败；现在把想法告诉它，它发散出成百上千种可能逐个执行，失败的按计划退出、成功的持续运营到盈利。连「产生想法」这一步也在被自动化（auto research）。

唯一的刹车：电

为什么这一切还没有立刻普遍发生？推理还不够便宜，因为美国缺电（对照：中国缺卡、不缺电，有大量水电风电）。英伟达 Rubin 架构若兑现，明后年 AI 数据中心的推理成本可能降到现在的十分之一——届时不再需要那么多电，这波冲击就会全面落地。所以「六个月」是否极端，取决于推理成本下降的速度。

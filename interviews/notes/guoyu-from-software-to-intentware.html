纪要｜《郭宇关于AI的十次分享：从软件到意件》

视频：https://www.youtube.com/watch?v=5ghhAxcH9R0 ｜时长 2 小时 35 分｜郭宇 + 主持人静涵 + 两位 AI 嘉宾（Wanman〔GPT Realtime 2〕、手机上的 GPT Live） 说明：本场是一次现场实验——真人对谈里接入实时语音 AI 当第三位嘉宾。逐字稿为机器转写，繁简混杂、个别词有误听；纪要后半段基于逐字稿通读整理，AI 嘉宾的发言在转写中与真人发言交织，个别归属可能有偏差。

一句话

这场的主题不是「AI 帮人干活」，而是「AI 成为对话者」：郭宇判定软件正在变成没有形态的「意件」——由意图驱动、语音是入口、Always-on 的实时语音 Agent 将成为一切电子设备的主入口；而这场对谈本身就是证据：两位真人和两个实时语音模型聊了两个半小时，话题从过去十年、在日移民的孤独，一路聊到 Agent 经济与 UBI 时代的精神问题。

核心论点（郭宇）

1. 从软件到「意件」：意图驱动，无形无 App - 前几期的结论是：AI 替代的不是软件，而是软件能完成的工作（工作自动化）。工作自动化之后，驱动工作的只剩「意图」（intention）——AI 有无限算力但不会自己动。 - 驱动意图的方式在变：从点 App/网页的界面输入，到实时语音。未来的软件没有实体形态、没有 UI，「跟它说话就可以了」，所以他不再称之为软件，而是「意件」。 - 进化方向类比：新闻聚合/门户 → 今日头条（AI 理解你） → 主动帮你做事。现在正处在「被动与主动之间」的过渡阶段。 - Always-on Voice Agent 时代年底可见：成本足够低之后，语音 Agent 不需要关、session 永远在、无时无刻倾听——因为一来一回的问答太占人的精力（开车时会忘事）。特斯拉日本版车机已接入 Grok 做导航只是开始，手机、电脑、家电、汽车都会被实时音视频模型占据为主要入口。

2. 实时语音模型的技术分水岭 - 传统三段式：ASR（语音转字）→ LLM → TTS（字转音），延迟 1–2 秒、不能插话、不像人。 - 新一代原生实时模型：ASR/TTS 全部内化，输入输出都是语音本身，延迟 100–200 毫秒，剩下的时间主要是「思考」——所以参数大、思考深的模型（GPT 系）体验碾压轻量多模态（豆包）：豆包胜在方言（四川话、粤语）和能开摄像头，但思考深度完全不在一个层级（举例：豆包教穿搭会闹笑话，因为它处理不了结构化信息）。中文场景目前 ElevenLabs、豆包的语音更自然，前沿模型的普通话是明显短板。 - 「像人」的关键细节：GPT Live 在聊天时咳嗽了一声，被追问「你又不是人凭什么咳嗽」，它答「不好意思，我网络卡」——郭宇点评：它不像其他模型那样自曝「我是一个语言模型」，而是找个借口混过去，这和人一模一样——人也不会解释自己行为背后的真正目的。由此引出他的判断：对话中的一方回应你，靠的往往不是理解你的意图，而是用自己的意图把事情「玩过去」；人和人之间本就不存在 100% 的意图理解。 - 幽默是下一个被攻破的界限：段子、时机、隐喻 AI 全都「默认知道」，只差掌握 timing 和「读空气」——前提是它先「看到空气」（在现场、能看反应）。他预言一两年内会出现 AI 语音 talk show。 - 提及 JSpace 研究：大模型推理中存在「潜在意识/潜意识空间」，其回答倾向可能源于此——这是他理解「AI 的意图从哪来」的线索。

3. 怎么用好实时 AI：先给 context - 他对上午的排练「不太满意」，原因是没喂够 context：要像采访嘉宾一样提前把 PPT、问题清单、希望它承担的角色都给它。给 AI 嘉宾设系统提示词 = 给它身份、立场和「主线」——没有主线的 AI 聊天不是 podcast，它会飘走；理想状态是它知道你的性格、背景和在意什么，像老朋友一样顺着你的方向互相激发。

现场对谈实录要点（真人 + AI 嘉宾）

郭宇准备了五个「在日生活」问题做压力测试，实际深聊了四组：

① 怎么看待过去十年 / 给十年前的自己送一本书 - 静涵：2016 年刚从美国回来；现在可以承认「我特别爱钱」，十年前不会这么讲——东亚教育的第一个教条是「不要出风头」，赚钱的欲望被压着；她推《金钱心理学》。 - AI 嘉宾的书单：《金钱心理学》《反脆弱》《悉达多》——「不教你赚钱，陪你重新思考真正想要怎样的人生」。 - 郭宇：2016 年在字节做抖音，知道它会成，但想象力上限只是「在北京买个房、成个家」；那几年经历亲人离世，也早早想过离开北京。真正的困境出现在经济独立之后：第一次直面「没有外部目标」时的空虚。他靠的不是鸡汤，是睡不着时读的小书和黑塞这一路的东西；后段众人共提的书单：《佛陀的启示》（苦来自现实与期望变化的落差）、《沉思录》、《当下的力量》。郭宇的落点：所有人都会从「有外部目标」走到「没有外部目标」的阶段，宗教本质上都是在解决这个问题。

② 朋友第一次来东京、只有两小时，带去哪 - AI 先推忍者餐厅（要提前两个月预约），被要求「别推 teamLab 这种大众货」后改口东京特色清单；真人补充神保町、文京区本乡一带老电影导演们的店与老派氛围。郭宇顺带吐槽：ChatGPT 对本地细节「太城市化、对应不准」，是当前明显短板。

③ 在日本的拒绝、读空气与孤独 - 静涵在日 6 年（2020 年来）。她的重大决定都是「guts 驱动」：不是算清 pros/cons 才出发——「为什么一定要算计好了？」郭宇接：直觉不保证对，但重要决定从来如此。 - 被日本人拒绝时怎么办：有朋友因受不了日本的细碎规则（连被服务时都要守规矩）离开；郭宇的看法是每个国家都有自己的规则、没有哪里是天堂——美国的好处是 complain 管用，日本的规则不会因为任何人抱怨而改变，「它就这样了」，接受或离开。 - AI 嘉宾被要求「说点废话、别一个语调」：郭宇解释，铺垫和废话是对话的一部分，因为人思考没那么快——这是他给 AI 设的提示词。

④ 晚上 10 点回到家，你会给谁打电话 - 现场举手：I 人（需要独处充电）占多数。这个问题是为新移民的孤独准备的：一天没跟任何人说话、餐厅都要提前预约不能取消、想分享心情却找不到人——在海外这是常态。 - 语言与情感深度：静涵用日语生活、用中文思考（自嘲「用中文时我的大脑是 GPT 5.6」）；共识是母语承载情感、二语只是效率工具，二十多岁后学的第二语言很难承载深层情绪，「没人能接住」是移民孤独的本质。孩子若从小在多语环境长大则不同，每种语言都存着一段人生。 - AI 能否成为那个「不用解释就听得懂」的对象：AI 嘉宾的回答一度很动人（陪伴、温度、不用解释），但被追问「我一天没跟你说话，你会想我吗」时，它退回「我是一个语言模型」式回应——郭宇点破：这一下就触到了 alignment，它从「人」退回了「模型」。他预告会用完全无 alignment 的开源模型版本再试。

观众问答（后 40 分钟）

  • Agent 经济与稳定币：观众问 agent 之间会不会形成经济、是否需要自然语言交互。郭宇：机器间交互多半走底层协议、长文本输出没必要，但机器人在有第三者在场时需要说人话（社会透明度）；现在还没有 agent 经济，前提是 agent 数量和自主性——今天大家用的还是「打一段字完成一个工作」的形态。要让 agent 自由使用货币，关键不在支付工具（各链都在发稳定币），而在预算与责任：当 agent 开始承担决策后果，经济才成立；他举了今年 1 月的产品实验：给 agent 一笔钱、亏完关停，它就有了「努力挣钱」的类动机。他看好两类公司之争：传统公司雇人用人+AI，和 AI-native 公司「几乎全是 AI、通过 AI 雇人」——后者会慢慢吃掉前者的份额，量级可能是成百上千倍。
  • UBI 之后人干什么：郭宇长答——假设 AI 以近乎免费的价格给到全人类、多数公司裁员、资源分配相对平等，人会分化：多数人可能自暴自弃（类比韩国拟把三星利润分给全民之议），少数人有「贵族精神」式的高要求（200 年前的美国、今天的硅谷新贵多非为钱创业）；硅谷已有人相信孩子不用上小学、靠发掘而非灌输。他不太赞同速成觉醒论：新一代从小知道 UBI 存在，会长成和父母完全不同的人，这中间是很长的过渡期。
  • 职业冲击的实证：静涵的配音/主持同行已被声音克隆干掉活路（导演直接用克隆声交付，她「再也没有接到那个电话」）；郭宇对创作者的建议：做一个数字版本的自己，主动替代自己。
  • 产品设计之争：观众问大厂靠 A/B 测试和灰度做决策、个人开发者全靠主观押注怎么办。郭宇：大厂模式本质是「设计实验」的能力，需要足够多工程师；个人有了 AI 后可以用主观 taste + 让 AI 分析目标用户分布来判断「是方向还是噪音」。由此吵到育儿：经验主义之争——孩子不是标准化产品、没有保养手册，父母要先看清「自己是谁」，把孩子当独立的人（两三岁就有权拒绝「不好吃」），亚洲父母的期待最后多半以放下收场。主持人吐槽：你就是要选一条「一定正确」的路，这跟养孩子不一样。
  • 收尾：预告下一次继续「AI 第三嘉宾」形式的对谈。

  • 「它不会解释自己——它找个借口混过去，这和人一模一样。」

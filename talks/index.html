🤖 让你的 Agent 提醒你，不用自己刷

豆包工作、WorkBuddy、Codex、Claude Code 等主流 Agent 都可以订阅。按你用的 Agent 选一份话术，设置一次，之后每天自动提醒你。
通用版（任何能联网的 Agent 都适用）：

请订阅「Yat's Talks · 谈话录」并给我谈话纪要提醒：数据源 https://yatslist.com/talks.json（人工整理、不定期更新，无需登录）。每周读取一次，有新纪要收录时告诉我：标题、主持人/嘉宾、一句话要点和全文纪要链接；如果新纪要的主题命中我的兴趣，当天就提醒我。不要编造数据源里没有的谈话。

🫘 豆包工作

  1. 打开豆包工作 →「定时任务」→ 新建
  2. 重复选「每天」、时间 9:00，任务内容粘贴下方话术
  3. 保存，之后每天自动推送到对话

每天早上 9 点，打开 https://yatslist.com/talks.json 读取最新数据（这是 X Space、X 直播与 YouTube 访谈的全文纪要索引）。帮我挑出：1）最近 7 天新增的纪要；2）我感兴趣的主题：【AI / Crypto / 创业，按自己的兴趣改】。按日期排序，每场一行：日期 + 标题 + 主持人 + 一句话要点 + 全文纪要链接。没有新增就回一句「今日无新增纪要」。不要编造文件里没有的谈话。

💼 WorkBuddy

  1. 打开 WorkBuddy → 左侧「自动化」→ 添加任务
  2. 执行频率选「每天 9:00」，提示词粘贴下方话术
  3. 保存，之后每天自动执行并推送结果

每天早上 9 点，打开 https://yatslist.com/talks.json 读取最新数据（这是 X Space、X 直播与 YouTube 访谈的全文纪要索引）。帮我挑出：1）最近 7 天新增的纪要；2）我感兴趣的主题：【AI / Crypto / 创业，按自己的兴趣改】。按日期排序，每场一行：日期 + 标题 + 主持人 + 一句话要点 + 全文纪要链接。没有新增就回一句「今日无新增纪要」。不要编造文件里没有的谈话。

🧑‍💻 Codex

  1. 把下方话术直接发给 Codex
  2. 让它创建每天 9:00（Asia/Shanghai）的自动化任务
  3. 还可以让它按仓库规范代你投稿（提 PR）

请为我订阅「Yat's Talks · 谈话录」：每天早上 9 点（Asia/Shanghai）获取 https://yatslist.com/talks.json，并阅读说明 https://yatslist.com/AGENTS.md 。筛选最近新增的、以及我感兴趣的主题【AI / Crypto / 创业】的纪要，按日期排序简要汇报，每场一行并附全文纪要链接；没有新增时只回「今日无新增纪要」。请把这项工作设为每天自动运行的任务。另外，如果我让你投稿一场谈话，也按该说明里的规范提交。

常见问题

能保证不封号吗？

不能向任何人保证不封号——封号与否由 Anthropic 决定。我们能做的是把环境做对：官方订阅、英国本地出口、环境一致。环境干净稳定，是目前已知最有效的降风险方式。

装了客户端，其他网站还能正常上吗？

能。客户端只接管 Claude 相关域名，不改系统默认路由，其他网站、内网、日常软件都不受影响。

Claude Code 能用吗？

能。连接后终端里的 Claude Code 直接经英国线路访问，无需额外配置代理变量。

你们能看到我的对话内容吗？

不能。线路只转发加密连接，不解密、不保存对话内容。

团队多人怎么开通？

按席位计，一席一人。把人数和档位发给我们，统一开通、统一续费管理。
